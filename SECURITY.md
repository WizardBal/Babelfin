# Security

Babelfin is beta software. Use the latest beta with a supported Jellyfin server and keep backups. Native applications and physical devices have not all been verified; the README identifies the tested paths.

## Report a vulnerability privately

Use GitHub's **Security → Report a vulnerability** option for this repository when available. Do not post exploit details, credentials, user data, media paths or unsanitized logs in a public issue.

If private reporting is unavailable, open a minimal issue requesting a private reporting channel without including the vulnerability details or any sensitive data. Wait for a private channel before sharing those details. No response time is guaranteed.

Reports should identify affected Babelfin/Jellyfin/app versions, the impact, reproduction steps and relevant sanitized evidence. Settings exports and activity logs can contain per-person viewing history; share only the minimum data needed.
